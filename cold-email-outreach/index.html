Cold-Email-Outreach

A personal, owner-operated workflow for organizing professional engineering contacts, preparing individualized networking email drafts, and tracking outreach for internship recruiting.

This is not a public email service. The application is currently built for the developer's own use. It prepares email drafts in a connected Google account; the owner reviews and sends any message manually.

What the application does

  • Google Sheets: Reads and updates a designated private contact tracker containing professional names, roles, work email addresses, research notes, and draft status.
  • Gmail: Confirms the connected account and creates or checks unsent Gmail drafts. It does not automatically send messages or read inbox conversations.
  • Personalization: Uses entered contact details and role-based templates to tailor outreach. Contact-specific claims are used only when an observation and a source URL have been supplied; the current workflow does not independently verify that source.
  • Automation: Runs Python code using GitHub Actions. Scheduled draft creation is currently disabled, and the workflow includes limits to prevent bulk drafting.
  • Optional contact lookup: Separate, manually authorized Apollo API lookups may be used to import professional contact information; this is not part of the Google account authorization flow.

Google permissions requested

The app requests Google's gmail.compose scope to manage drafts and spreadsheets scope to read and edit the designated contact tracker. These OAuth scopes grant broader technical capabilities than the functions currently used: in particular, gmail.compose also permits sending email, although this application's code has no email-sending operation. The workflow is designed for draft creation and manual review.

Authorization is optional and can be revoked through Google Account connections.
