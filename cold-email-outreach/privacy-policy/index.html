Cold-Email-Outreach

Privacy Policy

Last updated: November 22, 2026

This policy describes the current private, owner-operated version of Cold-Email-Outreach, developed by Jackson Ding. It is a Python and GitHub Actions utility for organizing professional contacts and preparing unsent networking email drafts. It does not offer a public account-registration service.

Google user data accessed

  • Google Sheets: With the https://www.googleapis.com/auth/spreadsheets permission, the application reads and edits the specifically configured Google Sheets contact tracker. It processes contact names, professional email addresses, job titles, companies, research notes, draft IDs, and outreach statuses. The OAuth permission itself can authorize access to other spreadsheets, but the current workflow uses only the spreadsheet configured by the owner.
  • Gmail: With the https://www.googleapis.com/auth/gmail.compose permission, the application checks the authorized account's email address, creates unsent Gmail drafts, and may retrieve a draft to verify its creation. The current code does not read inbox messages or send email. The scope technically permits sending, but the implemented workflows do not use that capability.
  • Authentication credentials: Google OAuth client details, refresh tokens, and short-lived access tokens are used solely to authenticate the owner's approved Google API requests.

How this data is used

Google user data is used only to operate the requested contact-tracking and Gmail-draft features, verify that the correct Google account is connected, prevent duplicate drafts, and perform owner-initiated connectivity checks. The application does not use Google user data for advertising, sale, profiling, or training generalized artificial-intelligence models. There is no automated email-sending feature.

Optional Apollo API contact lookups are a separate owner-initiated feature that retrieves professional contact information. The current Google integration does not transmit Google Sheets or Gmail user data to Apollo. No external AI research or generation service is connected to the current version of this application.

Storage, service providers, and security

  • Contact records and outreach status remain in the owner's designated Google Sheet. Draft messages remain in the owner's Gmail account.
  • OAuth refresh credentials are kept on the owner's own computer in a private local configuration file and in encrypted GitHub Actions repository secrets, rather than in the public website repository.
  • When a workflow is initiated, GitHub Actions temporarily runs the code and communicates with Google APIs over encrypted connections. Operational logs and metadata may be retained by GitHub under its service policies; the code is designed not to print tokens or entire contact lists.
  • Google and GitHub process relevant information as infrastructure providers for the requested features. No Google user data is sold or shared with advertising platforms.

The public documentation pages do not include sign-in forms, analytics scripts, or embedded trackers. Normal technical request logs may still be handled by the website's hosting provider.

Retention, access removal, and deletion

Contact records are retained in the Google Sheet until the owner edits or deletes them. Gmail drafts remain in Gmail until the owner deletes them or otherwise manages them. OAuth credentials remain available in the owner's local environment and GitHub repository secrets until replaced or deleted. GitHub workflow logs may be retained according to the repository's settings and GitHub's policies.

To stop access, revoke Cold-Email-Outreach in Google Account connections and remove the related OAuth credentials from GitHub Actions Secrets and any local configuration files. To remove contact or draft content, delete it from the relevant Google Sheet or Gmail account. For data-access or deletion questions, contact the developer below.

Google API Services User Data Policy

Use and transfer of information received from Google APIs by Cold-Email-Outreach adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is accessed only to provide or improve the app's user-facing functions, subject to the practices described in this policy.

Updates and contact

If the functionality or data processing changes, this policy will be updated before those new uses are enabled. For questions or requests regarding this application, contact jtding@engineering.upenn.edu.
